# Anida Dedelay — Fruit Restaurant 

## Live Demo
View Live here - https://react-ui-wn51.onrender.com/

## About
Anida Dedelay is a responsive restaurant website built as part of the ReactTS UI Challenge. 
It showcases a modern fruit restaurant with a hero section, menu cards, and an orange benefits 
section. The project focuses on reusable React components, TypeScript props, and CSS responsiveness.

## Installation & Setup

Clone the repository:
```bash
git clone https://github.com/Neliswa084/ReactTS_UI
```

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

## Tech Stack
- React
- TypeScript
- Vite
- CSS Modules

## Features
- Responsive navbar with mobile hamburger menu
- Hero section with call to action buttons
- Reusable menu cards rendered from an array
- Orange benefit section
- Footer
